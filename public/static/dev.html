Documentation Topics

🏗️ Architecture

Boot flow, component hierarchy, state management via Index.tsx (god component), and 40+ custom hooks organized by domain.

🎨 Theming

Design tokens in index.css, useThemeEngine and useThemePresets hooks, and the visual Theme Editor app.

📱 Building Apps

Register apps in appRegistry.tsx (createAppRegistry factory), add a switch case in WindowManager.tsx. Supports minimalInclude, standardInclude, and downloadable flags.

💻 Terminal & Scripts

Built-in commands (ls, cd, cat, sudo, etc.) and the TerminalScript system for saving/running multi-command sequences.

📡 SystemBus API

Typed event bus with SystemEventType enum: TRIGGER_CRASH, TRIGGER_BUGCHECK, TRIGGER_LOCKDOWN, ENTER_RECOVERY, etc. Convenience methods like triggerCrash(), triggerReboot().

📦 UUR Packages

In-simulation package repository for community-created apps. Submit via UUR app, reviewed by moderation team.

🤝 Contributing

Project structure, version bump checklist (version.json, index.html title, ChangelogDialog), and PR workflow.

Adding a New App (Quick Reference)

// 1. Create component: src/components/apps/MyApp.tsx // 2. Register in src/lib/appRegistry.tsx: { id: "my-app", name: "My App", icon: <Rocket />, run: () => openAppById("my-app"), standardInclude: true } // 3. Add switch case in src/components/WindowManager.tsx: case "my-app": return <MyApp windowId={window.id} />;
💡 Tip: Apps receive a windowId prop. Use semantic color classes like bg-background for theming support. Use h-full flex flex-col as root layout.
